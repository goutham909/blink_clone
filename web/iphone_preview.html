Seeing an old UI? Serve the build/web folder (not web/ alone), then run flutter build web after code changes. Hard-reload the iframe: right-click inside the phone → Reload Frame, or press Ctrl+Shift+R with DevTools open and cache disabled.

From the project folder: flutter build web, then serve build/web (e.g. python -m http.server 8080 inside build/web). Or: flutter run -d web-server --web-port=8080 and open /iphone_preview.html on that origin.
